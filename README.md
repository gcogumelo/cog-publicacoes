## Conteúdo

HTML e CSS sem dependências, JavaScript ou serviços de autenticação no site. A publicação é feita pelo GitHub Pages a partir da raiz da branch `main`, com `.nojekyll`.

As páginas apresentam o projeto e seus documentos. O uso da ferramenta é interno. A publicação deste site não representa aprovação de novas integrações ou APIs.

## Manutenção

Edite as páginas HTML e o arquivo `assets/styles.css`. Preserve links relativos compatíveis com o subdiretório `cog-publicacoes/`. Após alterar o conteúdo, confira navegação, visualização em celular e desktop e o canal de contato.

Este repositório contém somente materiais públicos do site. Não adicione credenciais, arquivos de configuração privados, registros operacionais ou conteúdo fornecido para publicação.
